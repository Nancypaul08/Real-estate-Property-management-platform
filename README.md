## Real Estate Property Management Platform

EstateHub is a frontend-only Real Estate Property Management Platform designed to provide a simple and user-friendly interface for property discovery, property management, and administrative management.

## Project Modules

### 👤 User Module
- Home page
- Property listing
- Property search
- Property details
- Login
- Registration
- Property inquiry

### 🏠 Owner Module
- Owner dashboard
- Add property
- Manage properties
- Edit property
- Property status

### ⚙️ Admin Module
- Admin dashboard
- Manage users
- Manage properties
- Manage bookings
- Platform statistics
